Notificaciones bonitas que reemplazan los alerts nativos

🎯 Prueba las Notificaciones

Ejemplo de código:
window.notify.success('¡Producto agregado!');
window.notify.error('Error al procesar');
window.notify.warning('Cuidado con esto');
window.notify.info('Información importante');

📊 Comparación: Antes vs Ahora

❌ Antes (alert nativo)

alert('Producto agregado al carrito');
// ❌ Bloquea toda la UI
// ❌ Diseño feo del navegador
// ❌ Solo un botón "OK"

✅ Ahora (notificación bonita)

window.notify.success('✓ Producto agregado al carrito');
// ✅ No bloquea la UI
// ✅ Diseño bonito personalizado
// ✅ Auto-cierre + cierre manual
